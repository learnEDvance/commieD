# co-up - Plan

## Core Idea
- Multiplayer maze shooter (browser-based)
- Large scale: 1000s of concurrent players across 200 cities globally
- Goal: be the last player standing
- Teams form via connections (max 3 per player)
- Shared pool of resources per team (distributed)
- Time is universal currency (earned 1/sec)
- Death: out of current game (killer gets random drop)
- When only 1 team remains, divide repeatedly until 1 player left
- Thick walls, simple shapes, minimal UI
